# Three.js Journey

This repository is based on the **Three.js Journey** course by Bruno Simon: [https://threejs-journey.com/](https://threejs-journey.com/).

I have added comments and changed some code while working through the lessons for my own understanding.

## Running a project

Each folder at the repository root is an **independent** project with its own dependencies.

1. `cd` into the folder you want to run.
2. `pnpm install`
3. `pnpm dev`
